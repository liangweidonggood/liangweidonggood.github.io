一、2016 年的 Windows 媒体工具

2016 年是直播元年——斗鱼 / 熊猫 TV / 虎牙崛起，OBS Studio 2016-09 取代 OBS Classic 成为新标准；PotPlayer 在 Daum 团队手里已经迭代到 1.6；YoloMouse 解决跨游戏鼠标灵敏度问题。本文整理三件套的实战用法。

阅读建议：本文面向视频制作 / 直播 / 录屏用户，重点在PotPlayer 调优 + OBS Studio 编码。

二、PotPlayer：万能播放器

2.1 定位

PotPlayer 2008 年由 KMPlayer 团队（后被 Daum 收购）开发，Windows 平台上最强本地播放器。优势：

  • 几乎所有格式（含蓝光原盘）
  • 硬件解码（DXVA2 / NVDec / Quick Sync）
  • 自定义滤镜链
  • 字幕外挂 / 内嵌
  • 完全免费（无广告 / 无捆绑）

2.2 安装

官方 https://potplayer.daum.net/：

  • 64 位版（推荐）
  • 安装时取消勾选"OpenCandy"广告插件（装好会自动取消）

2.3 首次配置

F5 → 选项 → 关键项：

配置推荐
视频 → 渲染器EVR / EVR CP（兼容性最好）
视频 → 解码器内置解码器 / LAV Filter（LAV 更强）
视频 → 硬件加速☑ DXVA2 / NVDec
视频 → 倍帧关闭（省电）
字幕 → 字体微软雅黑 18px
字幕 → 自动加载☑ 同名字幕
声音音轨 1 / 立体声

2.4 关键快捷键

快捷键作用
空格播放/暂停
→ / ←前进/后退 5 秒
↑ / ↓音量 +/-
D下一字幕
F全屏
B章节列表
J跳到下一文件
Tab显示时间轴
Z0.5x 速度
X1.5x 速度
C2x 速度
Shift + S截图（当前帧）

2.5 高级功能

3D 视频：左右半宽、上下半高、蓝光 3D（需要 3D 显示器）。

画面处理：

  • Ctrl + E：去交错
  • Ctrl + I：锐化
  • Ctrl + M：字幕缩放
  • Ctrl + D：去噪

TV 录制源：支持 .ts/.wtv 文件。

字幕翻译：右键 → 字幕 → 在线翻译（依赖 Google 翻译 API）。

2.6 LAV Filter 替代内置

LAV Filter 是开源的解码器集合，比 PotPlayer 内置解码器强：

  1. https://github.com/Nevcairiel/LAVFilters/releases 下载安装
  2. PotPlayer F5 → 内置视频解码器/音频解码器 → 全部禁用
  3. 安装 LAV Filter → 自动接管

优势：

  • 更好的色彩（10bit）
  • 更准的字幕（PGS 字幕）
  • 更强的硬件加速（NVDec 0.9+）

2.7 常见问题

画面卡顿：

  • 关闭硬件加速
  • 切换到 VMR9 渲染器
  • 升级显卡驱动

字幕乱码：

  • 字体编码选 UTF-8
  • 字幕文件另存为 UTF-8

播放 4K 卡：

  • 强制硬件解码
  • 升 SSD
  • 用 PotPlayer 1.7+（NVDec 优化）

三、OBS Studio：直播录屏标准

3.1 定位

OBS Studio 2012 年起开源，2016-09 取代 OBS Classic。完全免费开源，支持所有主流直播平台。

3.2 安装

https://obsproject.com/：

  • Windows 10/11 64 位
  • 安装时选好"安装 VS 2019 运行时"
  • 装好首次启动会跑自动配置向导

3.3 核心概念

场景（Scene）：一个完整画面。

来源（Source）：场景里的元素：

  • 显示器捕获：整个屏幕
  • 窗口捕获：单个应用
  • 摄像头：本地摄像头
  • 音频：麦克风 / 系统声音
  • 图片 / 视频 / 文本：贴图
  • 浏览器：网页 + CSS

输出：

  • 录制：保存到本地
  • 推流：推送到 B 站 / 斗鱼 / Twitch

3.4 关键配置

设置 → 输出：

配置推荐
输出模式高级（控制更细）
录像格式MKV（稳定）→ 转封装为 MP4
录像编码器x264 / NVENC H.264（GPU 加速）/ NVENC HEVC
录像质量CQP 18-23（质量优先）/ CBR 8000 kbps（稳定）
录像路径D:\videos\obs\

设置 → 视频：

配置推荐
基础分辨率1920×1080（显示器原生）
输出分辨率1920×1080 / 1280×720
FPS30（够用） / 60（游戏直播）

设置 → 推流：

  • B 站：rtmp://live-push.bilivideo.com/live-bvc/
  • 斗鱼：rtmp://sendtc3.douyu.com/live/
  • Twitch：rtmp://live.twitch.tv/app/<STREAM_KEY>

3.5 直播场景示例

游戏直播：

  1. 场景：游戏画面 + 摄像头 + 弹幕 + 字幕
  2. 来源：
    • 游戏捕获（全屏）
    • 摄像头（小窗 200×150）
    • 文本（房间信息）
  3. 编码：NVENC H.264 / CQP 20

会议 / 培训：

  1. 场景：演讲者画面 + 屏幕共享
  2. 来源：
    • 窗口捕获（PPT）
    • 摄像头（主讲人）
    • 音频（麦克风）

3.6 录制 + 转封装为 MP4

OBS 的 MP4 录制崩溃会损坏文件，推荐 MKV → MP4：

  1. 录制时选 MKV
  2. 完成 → 文件 → 录制转封装 → 选 MKV → 输出 MP4
1
2

# 命令行转封装（FFmpeg）
ffmpeg -i input.mkv -c copy output.mp4

3.7 常见问题

黑屏：

  • 用 显示器捕获 替代 游戏捕获
  • 显卡驱动升级
  • OBS 用管理员身份运行

音频卡顿：

  • 采样率统一 48 kHz
  • 用 麦克风/桌面音频 单独源
  • 关掉 OBS 内的"噪音抑制"

CPU 占用高：

  • 换 NVENC / Quick Sync 硬件编码
  • 降低分辨率 / FPS
  • 关闭 Psycho Visual Tuning

推流掉帧：

  • 用 网络测试 检查带宽
  • 升级到企业宽带
  • 换 CDN 平台

四、YoloMouse：跨游戏鼠标锁定

4.1 定位

YoloMouse 解决"每个游戏鼠标灵敏度不同"问题——FPS 玩家经常在多个游戏间切换，每个游戏的视角转换比例不同。YoloMouse 可以在每款游戏启动时自动设置鼠标加速度 / DPI。

4.2 安装

https://store.steampowered.com/app/560160/YoloMouse/（Steam 平台）：

  • 免费版：基础功能
  • 付费版（$5）：多配置文件 + 启动器集成

4.3 核心功能

Per-Game Profiles：每款游戏独立配置

加速曲线：自定义鼠标加速度

DPI 切换：自动切到游戏的最佳 DPI

指针加速：enhance pointer precision 强制开关

4.4 实战：CS:GO + 守望先锋双修

游戏鼠标加速度DPI
CS:GO0.0（纯线性）800
守望先锋0.01600
Apex 英雄0.5800
瓦罗兰特0.0800

保存为 4 个 Profile，启动时自动切换。

4.5 替代品

工具优势
YoloMousePer-Game + 启动器集成
RawAccel开源 + 高度可定制度
MarkC 鼠标修复Win 7/10 加速曲线
Logitech G HUB鼠标自带（只对罗技）
Razer Synapse雷蛇鼠标自带

六、常见问题

6.1 OBS 黑屏

最常见：

  • 显卡驱动不兼容（特别是 AMD）→ 升级到最新
  • 显示器多屏时 显示器捕获 选错
  • 用 DX11 游戏时 游戏捕获 选"捕获全屏"

解法：

1
2
3

1. 设置 → 视频 → 渲染器 → Direct3D 11
2. 用管理员身份运行 OBS
3. 关掉 GPU 加速（兼容模式）

6.2 PotPlayer 4K 卡顿

1
2
3
4

1. F5 → 视频 → 解码器 → 全部用 LAV
2. 视频 → 硬件加速 → 选 NVDec
3. 关闭"倍帧"和"图像增强"
4. 用 PotPlayer 1.7+

6.3 YoloMouse 不生效

  • 装付费版才有完整 Per-Game
  • 杀毒软件会拦截
  • 需要以管理员身份启动游戏

6.4 OBS 输出 0 KB

  • 路径没有写权限
  • 磁盘空间满
  • 编码器失败 → 切到 x264
