微信生态账号体系

微信公众平台 2012 年上线，10 年演化形成 4 大账号类型：

账号定位注册主体
服务号企业服务、客户管理企业 / 政府 / 媒体 / 其他组织
订阅号内容传播、资讯个人 / 媒体 / 企业 / 政府 / 其他组织
小程序应用形态、随用随走个人 / 企业 / 政府 / 媒体 / 其他组织
企业微信内部办公、上下游连接企业

重要规则：每个邮箱仅能申请一种账号。

一、服务号（Service Account）

定位

为企业和组织提供更强大的业务服务与用户管理能力，主要偏向服务类交互（功能类似 12315、114、银行，提供绑定信息、服务交互）。

适用人群

媒体、企业、政府或其他组织。

群发次数

服务号 1 个月内（按自然月）可发送 4 条群发消息。

能力

能力详情
微信支付✅ 支持
模板消息✅（后改为订阅消息）
自定义菜单✅
客服接口✅
微信小店✅
会员卡 / 优惠券✅
开放接口✅（OAuth、JS-SDK）
高级接口✅（设备、卡券、微信连 Wi-Fi）

选型建议

如果想用公众号获得更多功能，例如开通微信支付，建议选择服务号。

二、订阅号（Subscription Account）

定位

为媒体和个人提供一种新的信息传播方式，主要功能是在微信侧给用户传达资讯（功能类似报纸杂志，提供新闻信息或娱乐趣事）。

适用人群

个人、媒体、企业、政府或其他组织。

群发次数

订阅号（认证用户、非认证用户）1 天内可群发 1 条消息。

能力

能力详情
微信支付❌（个人订阅号不支持）
模板消息❌（改为订阅消息后可）
自定义菜单✅
原创保护✅（赞赏、留言、原创声明）
文章留言✅（已认证）
流量主✅（粉丝 500+）
微信小程序关联✅

选型建议

如果想用公众平台简单发发消息、做宣传推广服务，建议可选择订阅号。

三、小程序（Mini Program）

定位

小程序是一种新的开放能力，开发者可以快速地开发一个小程序。小程序可以在微信内被便捷地获取和传播，同时具有出色的使用体验。

注册范围

个人、企业、政府、媒体、其他组织。

接入流程

1

注册 → 小程序信息完善 → 开发小程序 → 提交审核和发布

关键规则

  • 每个邮箱仅能申请一个小程序
  • AppID 是唯一标识
  • 包大小限制：主包 2MB，总包 16MB（小游戏 4MB）

选型建议

适合功能闭环、轻量级、用户高频使用的应用。如电商、工具、内容。

四、企业微信（WeCom）

定位

企业的专业办公管理工具。与微信一致的沟通体验，提供丰富免费的办公应用，并与微信消息、小程序、微信支付等互通，助力企业高效办公和管理。

能力

  • 与个人微信消息互通（2019 起）
  • 上下游连接（供应商 / 经销商）
  • 内部审批、会议、文档、邮件
  • 客户联系、客户群、客户朋友圈

注册流程

1. 准备材料

账号类型需要的材料
个人订阅号身份证 + 手机号 + 邮箱
企业服务号营业执照、法人身份证、对公账户（认证时）
企业订阅号营业执照
小程序身份证（个人）/ 营业执照（企业）
企业微信营业执照 + 管理员授权

2. 注册入口

  • 公众平台：https://mp.weixin.qq.com
  • 小程序后台：https://mp.weixin.qq.com（同公众平台）
  • 企业微信：https://work.weixin.qq.com

3. 邮箱选择

重要：邮箱一旦注册过任一种微信账号，不能再次注册另一种。建议：

  • 个人号：用不重要的邮箱（如 QQ 邮箱、163 邮箱）
  • 企业号：用企业域名邮箱（更专业）
  • 多账号：准备多个邮箱

4. 信息登记

  • 个人订阅号：身份证 + 手机扫码
  • 企业服务号：营业执照（彩色扫描件）+ 法人身份证（正反面）+ 对公账户信息（认证用）

5. 主体认证

  • 个人订阅号：免费
  • 企业账号：300 元/年（认证费）
  • 认证后：获得更多接口权限、显示认证标识

互推联动

四类账号可以互相绑定：

  • 公众号 + 小程序：公众号菜单 → 小程序、小程序 → 公众号文章
  • 公众号 + 企业微信：公众号粉丝 → 引导加企业微信客服
  • 小程序 + 视频号：视频号 → 挂载小程序

常见问题

注册哪个最合适？

90% 情况选订阅号：内容、推广、品牌建设。支付 + 客户管理选服务号。功能型应用选小程序。

个人能注册哪些？

  • 个人订阅号 ✅
  • 个人小程序 ✅（部分类目受限）
  • 个人服务号 ❌

微信认证每年都要做吗？

是的，企业号每年 300 元。过期后部分接口受限（如微信支付）。

一个身份证能注册几个账号？

  • 个人订阅号 / 个人小程序：5 个（2018 后政策）
  • 企业主体：50 个
