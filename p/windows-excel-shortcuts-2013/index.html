一、为什么 Excel “够用就行"却总是不够

对运维、研发、商务、财务甚至运营来说，Excel 是所有人电脑里真正"日均打开"的工具——代码编辑器可以选 Vim 还是 VS Code，但数据透视、报表、临时统计几乎一定回到 Excel。然而，大多数人只用到 5% 的功能：

  • 表头滚三屏找不到对应列？
  • 想在表里塞个 ° 度数符号、× 乘号、÷ 除号，结果从搜狗拼音里翻了半天？
  • 合并单元格导致排序和筛选全部罢工？
  • 别人发来的 CSV 打开全是科学计数法？

本文把"日常办公 + 工程师偶尔用到的"小技巧整理成速查单，全部基于 Excel 2010/2013/2016/2021 通用功能，不含高阶 VBA / Power Query 之类需要单独成文的特性。

二、表头管理三件套

2.1 冻结首行：滚屏不丢列名

视图 → 冻结窗格 → 冻结首行

冻结后，无论向下翻多少行，第 1 行永远钉在顶部。这是看长表时最基本的体验改进。

如果要冻结"前 N 行"或"前 N 列”，把光标先点到目标位置右下角的格子（比如想冻结前 2 行 + 前 2 列，就点 C3），再选"冻结拆分窗格"。

2.2 取消冻结

视图 → 冻结窗格 → 取消冻结窗格

注意：如果你存了 .xlsx 但用的是"保护工作表"模式，冻结状态会被锁住——这时需要先"撤销工作表保护"才能动。

2.3 冻结 vs 拆分窗格的差异

功能冻结窗格拆分窗格
行为顶部 / 左侧的行 / 列固定不动拖动中间的分隔条滚动两边
适合看长表（永远要看到表头）对照同一行 / 列的两段数据
视觉没有分隔条有一条可拖动的横 / 竖分隔条

日常用前者就够；做数据对比、核对前后差异时后者更顺手。

三、Alt 码：键盘能打出的"特殊字符全集"

3.1 核心玩法

按住 Alt 键不放，在数字小键盘上输入数字序列，松开 Alt 后字符就出现在光标位置。例如：

  • Alt + 0176 = °（度数符号）
  • Alt + 248 = °（度数符号，扩展码）

两条路径都能打出同一个符号，区别是 3 位数字（0176）走 ANSI 编码，4 位数字（0256 以上）走扩展 ASCII / Unicode。

3.2 高频特殊符号速查

字符Alt 码含义典型场景
°0176 / 248度数符号温度 / 角度
±0177正负号公差标注
×0215乘号公式 / 数学
÷0247除号公式 / 数学
µ0181微（10⁻⁶）单位
Ω234欧姆电阻
©0169版权符号文档署名
®0174注册商标商标
™0153商标（Trademark）品牌
§0167章节符号法律文本
¶0182段落符号排版
¥0165人民币价格
€0128欧元跨国报表
£0163英镑跨国报表
→026右箭头流程图 / 描述
←027左箭头流程图 / 描述
↑024上箭头排序符号
↓025下箭头排序符号
★9733实心星评分
☆9734空心星评分
✓10003对勾完成标记
✗10007叉错误标记
0160不间断空格排版（防换行）
–0150短破折号范围表达
—0151长破折号文学排版

范围：3 位 Alt 码 01520255、4 位 Alt 码 0256065535 都可输入。但只有 0256 以下是 ANSI 高位字符（如拉丁扩展、希腊字母、西里尔文），0256 以上是 Unicode 范围——所以用 4 位 Alt 码能打出几乎所有 Unicode 字符。

3.3 注意事项

  • 必须用数字小键盘输入，外接笔记本键盘没有小键盘的话按 Fn + NumLk 切到模拟数字键盘
  • 输入时不需要补 0：0181 输 181 也行（Excel/Word 等 Office 软件自动补 0）
  • 中文输入法状态下 Alt 码会被拦截，先切到英文输入法再按 Alt
  • 在 Windows 10/11 22H2 之后，部分 Unicode 字符可用 Win + .（表情符号面板）或 Win + ; 直接选，比记 Alt 码更方便

四、打印与页面设置

4.1 强制每页都打表头

做月度报表时常遇到：第一页有表头，第二页开始就光秃秃的。解决办法：

页面布局 → 打印标题 → 顶端标题行 → 选 $1:$1

这样每一页都会重复打印第 1 行。

4.2 一页纸打印

页面布局 → 缩放 → 调整 “缩放比例” 到 60~80%，或选 “将整个工作表打印在一页”

如果是宽表（列很多），需要"横向打印"：

页面布局 → 方向 → 横向

4.3 取消分页虚线

文件 → 选项 → 高级 → 取消勾选"显示分页符"

或者在视图里切到"分页预览"再切回"普通"，分页线就会暂时消失。

五、CSV / 大数据打开策略

5.1 数字被科学计数法吞了

别人发的 CSV 用 Excel 打开，手机号、身份证号、长 ID 全变 1.38E+10——这是 Excel 默认按数字解析。两种应对：

  1. 导入时指定列文本：数据 → 自文本/获取数据 → 从文本/CSV → 选文件 → 转换 → 把对应列设为"文本"
  2. 事前转格式：在 CSV 里给数字加单引号前缀（'13800000000），Excel 看到前导单引号就当文本处理

5.2 大文件打开慢 / 卡死

50 万行以上建议直接用 Power Query（数据 → 获取数据 → 从文件 → 从工作簿），不要双击打开。Power Query 是流式处理，50 万行也能秒开。

5.3 替代工具

场景推荐工具
< 1 万行常规表格Excel 本身
1 万 ~ 100 万行Power Query（Excel 自带）
> 100 万行pandas + Jupyter（Python）
跨平台团队协作在线 Excel（Microsoft 365）/ Google Sheets

六、Excel vs WPS vs Google Sheets 横评（2013 时代）

2013 年的现状是：微软 Office 仍是事实标准，WPS 在国内有政府 / 教育市场，Google Sheets 在国内访问困难。

维度Microsoft Excel 2013WPS 表格Google Sheets
格式兼容性满分良好（偶有公式差异）良好（宏不兼容）
离线完整完整需联网
协作弱（2013 时代）弱实时协作（杀手锏）
VBA 宏完整部分支持Apps Script（语法不同）
价格商业付费个人版免费免费
国内访问完整完整困难

结论：日常办公 Excel 仍是首选；预算紧 / 政府 / 教育场景 WPS 完全够用；强协作 / 跨地域 才需要 Sheets。

七、常见 5 个坑

  1. 冻结窗格在受保护工作表里被锁——先"撤销工作表保护"再动。
  2. CSV 手机号变科学计数法——导入时强制设为"文本"，或数字前加 '。
  3. 合并单元格不能筛选——尽量别合并，或筛选前先取消合并。
  4. Alt 码打不出来——检查是否中文输入法、外接键盘没切到小键盘模式。
  5. 大文件 Excel 慢到怀疑人生——超过 50 万行就上 Power Query 或 pandas，别死磕。

八、总结

  • 冻结首行 = 80% 场景的"性价比之王"，比筛选 + 排序更省事
  • Alt 码 = 工程师记 20 个就够用一辈子（°×÷©®™µΩ→←↑↓）
  • CSV 数字 = 永远在导入阶段就指定类型，不要等打开后救火
  • 大文件 = Power Query / pandas，Excel 双击打开是错误用法
  • 协作 / 跨国 = Sheets；国内办公 = Excel 或 WPS
